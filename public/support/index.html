ChaiPhoto Support

支援與問題回報

這裡會作為 ChaiPhoto 的官方支援入口。

目前可以先做什麼？

若使用 TestFlight 測試版，可優先使用 TestFlight 內建的 Beta Feedback 回報截圖、操作情況與 Crash。

ChaiPhoto 自有的網站回報表單與管理後台會在下一階段加入。

回報時建議提供

App 版本與 Build、iOS 版本、iPhone 型號、發生問題前的操作步驟，以及不包含敏感照片或個人資料的截圖。

English

This is the official support page for ChaiPhoto. TestFlight users can currently use TestFlight Beta Feedback. A dedicated web feedback form and private management dashboard will be added in a later phase.
