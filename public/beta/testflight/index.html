安全與 Beta 風險說明

ChaiPhoto 使用 Apple TestFlight 分發，不需要企業憑證、來源不明描述檔、UDID 或 Developer Mode。 App 能使用的照片與影片仍受 iOS 權限控制，透過 TestFlight 安裝不會自動取得額外系統權限。

✓
目前已由開發者手動測試 目前沒有發現會影響基本整理流程的已知運作問題。
!
但 Beta 不是零風險 不同裝置、照片庫內容或操作方式仍可能遇到尚未發現的 Bug、介面異常、卡頓、閃退或其他使用體驗問題。
✓
這也是公開測試的目的 希望透過更多實際使用情境找出問題，再持續修正與改善。

加入後，更新怎麼知道？

新的 Beta 版本會直接出現在 TestFlight。是否收到推播通知取決於 TestFlight 與 iOS 的通知設定； 每個版本的「測試項目」會寫上這次更新了什麼，以及希望測試者特別確認的內容。 所以一般使用者不需要記 Build 編號，只要看 TestFlight 顯示的版本與更新說明即可。

遇到 Bug 或覺得哪裡不好用？

建議優先使用 ChaiPhoto 網站回報，問題會直接進入開發者的追蹤系統。 開發者每天早上約 08:00 會固定查看新的網站回報與相關通知。 App 內回報與 TestFlight 內建 Beta Feedback 也可以使用。
